03Reading a liveness counterexample

A safety failure is a bad state you can reach. A liveness failure is an infinite loop that never reaches a good outcome, so the counterexample is a lasso: a prefix, then a loop that repeats forever. Scrub the trace for the design without a timeout, then flip to the fix.
